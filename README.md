# PRISMA — Website institucional

Website demonstrativo em português (Angola), feito com HTML, CSS e JavaScript sem dependências de build.

## Executar localmente
Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático.

## Deploy na Vercel
1. Entre em https://vercel.com/new
2. Importe `layouter787-source/www.prisma.ao` do GitHub.
3. Deixe o Framework Preset como **Other**.
4. Deixe Build Command e Output Directory vazios (site estático na raiz).
5. Clique em **Deploy**.

Depois da ligação inicial, os pushes para a branch de produção configurada geram novos deployments automaticamente.

## Nota
PRISMA é uma marca e empresa fictícias para fins demonstrativos. Contactos, endereço de e-mail, serviços e dados institucionais são exemplos e devem ser substituídos antes de uso comercial.
